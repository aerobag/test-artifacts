# Test Data Notice

**TEST DATA ONLY - NOT FOR NAVIGATION**

This repository contains immutable historical aviation-data fixtures used for
automated software testing. They are not current operational data and must not
be used for flight planning, navigation, or any other safety-critical purpose.

The fixtures are not official FAA or NOAA products. Aerobag may preserve exact
upstream bytes where identifiers, references, timestamps, text, or encoding are
part of the behavior under test. Aerobag never serves these fixtures through
its live-feed publication path.
